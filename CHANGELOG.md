# Changelog

## 0.1.0 — research release candidate

- Package the frozen PepDDG rank-fusion method as an installable `pepddg` Python module and CLI.
- Add strict raw-feature scoring, linear-complex structure preparation, paired OpenMM channels, geometry features and bundled ProteinMPNN scoring.
- Add input identity checks, exact-input checkpoints, runtime diagnostics and frozen-feature SKEMPI replay.
- Document the scientific limits, historical MIT scope, new noncommercial terms and third-party assets.

This candidate is not yet a paper-level end-to-end SKEMPI reproduction. The frozen-feature replay and fresh structure workflow have separate validation gates. See [benchmark status](docs/BENCHMARK.md).
