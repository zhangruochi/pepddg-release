# Contributing

Please open an issue with a minimal input description and the `pepddg doctor --json` report before proposing a behavior change. Do not attach unpublished structures, private assay data or credentials to a public issue. For a code change, keep the predictor's feature definitions and cohort-relative ranking semantics explicit, add a meaningful regression test, and include the affected command and expected output in the pull request.

Changes to the scientific method require a versioned protocol, provenance and benchmark comparison. A passing frozen-feature test is not enough to claim end-to-end parity. Retain license and source notices when copying or modifying bundled components; see [license scope](LICENSE_SCOPE.md) and [third-party notices](THIRD_PARTY_NOTICES.md). Contributions are subject to the repository's license terms unless a separate written agreement says otherwise.
