# PepDDG package source

This directory is installed as the public `pepddg` Python package.
Use `pepddg score-features` for strict raw-feature scoring and
`pepddg score-structures` for complete structural inference.

See the [repository quick start](../../README.md),
[structural and Python API guide](../../docs/STRUCTURES.md), and
[reproducible examples](../../examples/skempi_cyclic/README.md).

The `_backend` directory contains bundled scientific producers and the
ProteinMPNN checkpoint. Source hashes and third-party notices are preserved
in `_backend/SOURCE_PROVENANCE.json` and the repository's
[third-party notices](../../THIRD_PARTY_NOTICES.md).
