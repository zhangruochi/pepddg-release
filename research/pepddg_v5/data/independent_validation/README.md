# Independent validation data

See `../DATA_PROVENANCE.md` for the canonical license, source DOIs, and
attribution for every file under this directory.

In short:
- **BPTI deep mutational scan** (`bpti_dms_*.xlsx/csv`) — Heyne et al., *eLife* (2021), CC-BY-4.0.
- **OOD targets** (`1CBW`, `2R9P`, `3OTJ` mutation CSVs) — derived from the same DMS dataset.
- **Crystal structures** — RCSB PDB, public domain.

If you redistribute or build on this data, please cite the original sources in
addition to this work.
